## 1. Supabase Row Level Security policies not recovered

**Category:** `rls-policy` · **Recoverable automatically:** no

RLS policies live server-side and are invisible to client capture. The generated schema creates tables WITHOUT policies (locked down by default).

**Manual migration steps:**

1. In your Supabase dashboard (self-hosted or cloud), open each table → Policies.
2. Recreate the policies from your Lovable project's Supabase settings (export via the Supabase CLI: `supabase db dump --role-only` against the original project if you still have access).
3. Test every policy with the app's real user roles before going live.
